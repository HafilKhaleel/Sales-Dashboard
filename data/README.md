# Data folder notes

`sales_sample.csv` is a tiny fictional teaching dataset created for this starter repository. It does not represent a real company, and its calculated totals are not project findings.

Place the untouched source file for your real project in `raw/`. The included Python script expects the documented columns and writes a cleaned file to `processed/`. Never publish personal, confidential, or unlicensed data. Check the source's license and attribution requirements before sharing it.
