# Sales Performance & Business Insights Dashboard

> **Starter project:** The included CSV contains a tiny, fictional sample created only to demonstrate the workflow. It is not real business data. Any numbers produced from it are examples, not findings about a real company. Replace it with a dataset you are allowed to use before making claims in a portfolio or resume.

A beginner-friendly portfolio project for exploring sales, revenue, profit, products, regions, customers, and monthly trends with SQL, Python/Pandas, Excel, and Power BI.

## What this repository contains

- A small fictional CSV so the code can run immediately.
- A Python script that checks and cleans the CSV, adds calculated columns, and writes a processed file.
- Starter SQL schema and analysis queries (SQLite syntax).
- Step-by-step instructions for opening the data in Excel and building a Power BI report.
- Places to save your own dashboard and screenshots.

## Data fields

The example file uses one row per order line. It includes `order_id`, `order_date`, `customer_id`, `customer_name`, `region`, `product_id`, `product_name`, `category`, `quantity`, `unit_price`, and `unit_cost`. Revenue is calculated as `quantity × unit_price`; profit is `revenue − quantity × unit_cost`. These definitions are assumptions for the starter example. Confirm the meanings in your real data, especially whether discounts, returns, tax, and shipping should be included.

## Set up on Windows

1. Install Python 3.10 or newer from [python.org](https://www.python.org/downloads/). During installation, select **Add Python to PATH**.
2. Download this repository from GitHub using **Code → Download ZIP**, then extract it. Or clone it with Git if you already use Git.
3. Open PowerShell in the extracted `sales-performance-dashboard` folder. In File Explorer, open the folder, click the address bar, type `powershell`, and press Enter.
4. Create and activate a project-specific Python environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that PowerShell window, then activate again. This affects only that window.

5. Install the packages:

   ```powershell
   py -m pip install -r requirements.txt
   ```

6. Run the example analysis:

   ```powershell
   py src/analyze_sales.py
   ```

   The script reads `data/raw/sales_sample.csv` and creates `data/processed/sales_clean.csv`. It prints row counts and a few totals for learning. They describe only the fictional sample.

To use your own data, save a copy as `data/raw/sales_sample.csv` with the documented columns, or edit the `INPUT_FILE` setting near the top of `src/analyze_sales.py`. Keep private or licensed data out of a public repository.

## SQL: explore the data

This project uses SQLite so you can practice SQL without setting up a database server. Python's standard library includes SQLite. One easy visual option is [DB Browser for SQLite](https://sqlitebrowser.org/).

1. Run the Python script first so `data/processed/sales_clean.csv` exists.
2. Open DB Browser for SQLite and create a database such as `data/sales_demo.db`.
3. Use **Execute SQL** to run `sql/01_create_tables.sql`.
4. Import `data/raw/sales_sample.csv` into the `sales` table using **File → Import → Table from CSV file**. It has the 11 source columns defined by the SQL table.
5. Run selected queries from `sql/02_analysis_queries.sql`. Update table/column names if your import wizard creates a different schema.

SQL files are examples to learn from. The raw CSV is used for the SQL table; the Python script separately creates a processed CSV with revenue, cost, and profit for Excel and Power BI.

## Excel: inspect and summarize

1. Open Excel and choose **Data → From Text/CSV**.
2. Select `data/processed/sales_clean.csv`, confirm comma as the delimiter, and load it.
3. Format `order_date` as a date and price/revenue/cost/profit columns as currency.
4. Select the data and choose **Insert → PivotTable**.
5. Try `region` in Rows and `revenue` and `profit` in Values. Add `category` or `order_date` to explore other views.
6. Save your workbook as `reports/excel/sales_analysis.xlsx`.

Your Excel version and menus may look slightly different. The workbook is your analysis artifact; do not describe example values as real findings.

## Power BI: build a dashboard

Power BI Desktop is a Windows application. Download it from the [official Power BI Desktop page](https://www.microsoft.com/power-platform/products/power-bi/desktop) (availability may depend on your Windows setup and region).

1. Open Power BI Desktop and choose **Get data → Text/CSV**.
2. Load `data/processed/sales_clean.csv` and choose **Transform Data** to check types. Set `order_date` to Date, quantity to Whole Number, and money columns to Decimal Number or Fixed Decimal Number.
3. Select **Close & Apply**.
4. Create a few visuals: revenue and profit cards; revenue by month; profit by region; and revenue by product or category. Add slicers for region, category, and date.
5. Use clear titles, currency formatting, and labels. Check whether totals make sense against the source file.
6. Save as `reports/powerbi/sales_dashboard.pbix`. If sharing screenshots, use data you are allowed to publish and remove sensitive customer information.

Suggested measures if you prefer DAX measures to the imported calculated columns:

```DAX
Total Revenue = SUM(sales_clean[revenue])
Total Profit = SUM(sales_clean[profit])
Profit Margin = DIVIDE([Total Profit], [Total Revenue])
Units Sold = SUM(sales_clean[quantity])
```

Format `Profit Margin` as a percentage. These are starter definitions; adapt them to how your source defines sales, costs, returns, and margin.

- Which regions contribute the most, and do high-revenue regions also have strong profit?
- Which customers or customer groups contribute most? Avoid publishing personal information.
